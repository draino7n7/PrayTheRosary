# game/AGENTS.md - Godot 4.7.2 Project & GDScript Rules

These rules apply to all files inside `game/` (`res://`), including scenes, scripts, autoloads, resources, export presets, and automated tests for the **Pray The Rosary** project.

---

## 1. File Encoding & Resource Integrity

- **UTF-8 Without BOM Only:** Godot's parser rejects `.tscn`, `.tres`, `.gd`, and `.cfg` files containing a UTF-8 Byte Order Mark (BOM) or UTF-16 encoding. Always create and edit files inside `game/` using the agent's native `write_file` and `edit_file` tools, never via PowerShell stream redirection (`>`).
- **Blank Line in `.tres` Resources:** When generating or editing `.tres` resource files manually, always preserve a blank line between the `[gd_resource ...]` / `[ext_resource ...]` headers and the `[resource]` block.
- **Commit `.uid` Files:** Stage and commit any `.uid` files generated by Godot alongside new or moved `.gd` scripts, scenes, and resources.
- **Export Filters for Non-Resource Files:** Godot's `export_filter="all_resources"` skips plain data files (`.json`, `.ttf`, `.txt`) unless matched in `include_filter`. In [`game/export_presets.cfg`](export_presets.cfg), keep `include_filter="*.json, *.ttf"` on both Android and Web presets so runtime JSON data and fonts are bundled.

## 2. GDScript Coding Standards

1. **Strict Static Typing:**
   - Every variable, constant, function parameter, and return type must have an explicit type annotation (`var reading_page: int = 1`, `func jump_to_page(target: int) -> void:`).
   - Avoid untyped `:=` inference when the right-hand side returns `Variant` (such as `get_node()`, `Dictionary.get()`, or `JSON.parse_string()`). Explicitly annotate the variable type and cast with `as`:
     ```gdscript
     var title_label: Label = get_node_or_null("Header/Title") as Label
     ```
2. **Naming Conventions:**
   - **Classes (`class_name`) & Scene Nodes:** `PascalCase` (e.g., `Main`, `NavigationDrawer`, `BasePageCard`)
   - **Functions, Variables & Signals:** `snake_case` (e.g., `current_page`, `page_selected`)
   - **Constants & Enum Values:** `UPPER_SNAKE_CASE` (e.g., `TOTAL_PAGES = 50`, `COLOR_GOLD`)
3. **Logging:**
   - Do not leave raw `print()` calls in gameplay, reader, or UI scripts.
   - Use `print_debug(...)` for diagnostic traces, `push_warning(...)` for recoverable anomalies, and `push_error(...)` for broken invariants.
4. **Documentation:**
   - Include a top-level `##` doc comment on every autoload, page card, and controller script describing its domain responsibility.

## 3. UI Layout & Cross-Platform Guardrails

- **Primary Font & Web/HTML5 Symbol Fallbacks:**
   - Browser WASM exports have no access to OS system fonts. Never assign a `SystemFont` as the default font or theme font, as doing so alters font metrics and breaks book page layout calculations.
   - The primary serif font is `EB Garamond` (`res://assets/fonts/EBGaramond-Regular.ttf`), configured in [`res://resources/rosary_theme.tres`](resources/rosary_theme.tres).
   - Any custom `FontVariation` or UI control displaying Unicode symbols (e.g., `☰`, `✕`, `▸`, `▾`, `★`, `▶`, `←`, `→`) must retain `res://assets/fonts/NotoSansSymbols-Regular.ttf` in its `fallbacks` array.
   - Whenever adding Unicode symbols to UI controls, add a unit test asserting `font.has_char(ord(ch))` against the active font.
- **Responsive Portrait Viewport & 2:3 PageCard Architecture:**
   - The base logical viewport is `720x1280` portrait (`canvas_items` stretch mode, `expand` aspect).
   - Book pages follow a 2:3 aspect ratio (`PageCard` architecture) modeled after the 6" x 9" physical book format.
   - Android full-screen immersive mode is enabled via `display/window/screen/immersive_mode=true` in `project.godot`.
   - Continuous scroll and navigation drawer controls must account for mobile cutouts and system bars via `DisplayServer.get_display_safe_area()` during `_ready()` and `NOTIFICATION_RESIZED`.
   - Remember that `GridContainer` collapses invisible children (`visible = false`). To hide a slot while preserving grid cell positions, keep `visible = true` and set `modulate.a = 0.0` or clear its text.

## 4. Automated Unit Testing (`game/tests/`)

- **Test Suite Location & Naming:** Place unit test scripts in `game/tests/test_<feature>.gd`. Every script must extend `TestBase` (`res://tests/test_base.gd`) and define `func test_<case>() -> void:` methods.
- **Lifecycle Hooks:** Override `before_each() -> void` and `after_each() -> void` on `TestBase` subclasses for per-test state setup and cleanup, or `cleanup() -> void` for suite-level teardown.
- **Available Assertions in `TestBase`:**
   - `assert_true(condition, message)` / `assert_false(condition, message)`
   - `assert_eq(actual, expected, message)` / `assert_ne(actual, expected, message)`
   - `assert_gt(actual, expected, message)` / `assert_gte(actual, expected, message)`
   - `assert_lt(actual, expected, message)` / `assert_lte(actual, expected, message)`
   - `assert_approx(actual, expected, tolerance, message)`
   - `assert_null(val, message)` / `assert_not_null(val, message)`
   - `assert_contains(haystack, needle, message)`
   - `assert_file_exists(path, message)`
- **Headless Test Runner Caveats:**
   - [`test_runner.gd`](tests/test_runner.gd) extends `SceneTree` directly and runs during `_init()`. Global autoload singletons defined in `project.godot` are not registered as global identifiers during `test_runner.gd` execution. Avoid hardcoding global singleton identifiers inside core logic classes; instead pass dependencies explicitly or resolve `/root/SingletonName` dynamically.
   - When instantiating `Node` or `Control` subclasses in tests, add them to `test_root_window.add_child(node)` if `_ready()` or theme propagation is required, and always destroy them immediately after the test using `node.free()` (never `queue_free()`, which leaks objects when the headless runner exits).
   - Lambda closures in GDScript capture primitive types (`int`, `bool`, `float`, `String`) by value. To count signal emissions inside a test lambda, mutate an `Array` or `Dictionary` wrapper (e.g., `var emitted: Array[bool] = [false]`).
   - Guard `DisplayServer` window/screen state assertions with `if DisplayServer.get_name() != "headless":`.
